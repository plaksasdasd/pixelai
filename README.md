# 🎨 Minecraft Skin AI Painter (Нейросеть для скинов Майнкрафт)

Добро пожаловать в проект **Minecraft Skin AI Painter**! Это полноценная нейросеть, созданная с нуля на **PyTorch**, которая умеет генерировать новые скины Майнкрафт (разрешением 64x64, в формате **RGBA** с поддержкой прозрачности) по вашему текстовому описанию (на русском или английском языках).

Проект поставляется с потрясающим интерактивным веб-интерфейсом на **Streamlit**, который поддерживает:
1. **Генерацию скинов** с текстовыми запросами, 2D-разверткой и **интерактивным 3D-просмотром** модели (можно крутить, приближать, включить анимацию ходьбы!).
2. **Мгновенное процедурное создание демо-датасета** из 100 скинов для быстрого теста обучения без поиска файлов в интернете.
3. **Обучение нейросети** прямо в браузере с графиком потерь (loss) в реальном времени и отображением промежуточных результатов.

---

## 🛠️ Архитектура Нейросети (Как это работает)

1. **Генератор (Generator):** Глубокая сверточная нейросеть с остаточными блоками (ResNet Blocks). На вход принимает случайный шум (вектор $z$, 128-dim) и вектор текстового описания. Использует алгоритм апсемплинга ближайшими соседями для обеспечения резких, пиксельных текстур без артефактов "шахматной доски". Выход — изображение 64x64x4 (RGBA, с поддержкой прозрачности внешней одежды и шлемов).
2. **Дискриминатор / Критик (Discriminator):** Сверточный критик на базе WGAN-GP. Оценивает реалистичность скина и его соответствие тексту. Чтобы обучение шло математически стабильно, здесь используется **Layer Normalization** (а не Batch/Instance Normalization): в WGAN-GP штраф на градиент (Gradient Penalty) накладывается на каждый пример отдельно, поэтому нормализация не должна смешивать статистики между примерами — иначе нарушается условие 1-Липшица и критик «убегает».
3. **Текстовый энкодер (Text Encoder):** Модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`. Она является мультиязычной и сопоставляет русские и английские фразы со схожим смыслом в единое векторное пространство (384-dim). Это значит, что вы можете обучать модель на английских файлах, а генерировать скины, делая запросы на русском языке!
4. **Стабильность (WGAN-GP):** Использование Wasserstein GAN с Gradient Penalty предотвращает схлопывание моды (mode collapse) и делает обучение стабильным даже на небольших наборах данных.

## 📦 Быстрый старт

### 1. Установка окружения
Убедитесь, что у вас установлен Python 3.8+ и PyTorch. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения 🚀
Запустите графический веб-интерфейс:

```bash
streamlit run app.py
```

Откройте в браузере адрес, указанный в консоли (обычно `http://localhost:8501`).

---

## 🏋️ Инструкция по обучению нейросети

В веб-интерфейсе вы найдете три удобные вкладки:

### Шаг 1: Создание или загрузка датасета
* Перейдите во вкладку **"Управление Датасетом"**.
* Нажмите кнопку **"Сгенерировать 100 демо-скинов"**. Наша программа мгновенно создаст 100 красивых пиксельных скинов разных классов (огненные демоны, кибер-ниндзя, ледяные маги, космонавты и др.) с готовыми описаниями в папке `dataset/`.
* *Или:* Перетащите ваши собственные файлы `.png` в окно загрузки. Назовите ваши файлы осмысленно (например: `golden_knight.png`), и нейросеть автоматически использует имя файла как текстовый запрос во время обучения!

### Шаг 2: Запуск обучения
* Перейдите во вкладку **"Обучение Нейросети"**.
* Выберите количество эпох (рекомендуется от 100 до 300 для первых тестов) и размер батча (по умолчанию 16).
* Нажмите **"Начать Обучение"**.
* Вы увидите динамические графики изменения лоссов генератора и критика, а также промежуточные превью того, как нейросеть учится рисовать!

### Шаг 3: Генерация вашего скина
* После успешного обучения перейдите в первую вкладку **"Генерация Скинов"**.
* Введите описание, например: `огненный демон с рогами` или `cyber ninja`.
* Нажмите **"Нарисовать скин"**.
* Любуйтесь 2D-текстурой, вращайте скин в **интерактивном 3D-просмотрщике** и скачайте файл `.png`, готовый к установке в Minecraft!

## 💻 Использование через консоль (CLI)

Вы также можете запускать скрипты напрямую из терминала:

### 1. Обучение:
```bash
python train.py --data_dir dataset --epochs 150 --batch_size 16
```

### 2. Генерация:
```bash
python generate.py --prompt "knight in dark armor with glowing purple eyes" --output generated_skin.png
```

## 📂 Структура проекта

* `app.py` — Главный файл Streamlit-интерфейса.
* `train.py` — Код обучения (WGAN-GP, оптимизаторы Adam, вычисление градиентного штрафа).
* `generate.py` — Код консольной генерации по промпту.
* `models/`
  * `generator.py` — Архитектура генератора (ResNet-блоки, транспонированная свёртка, Tanh).
  * `discriminator.py` — Архитектура критика (LayerNorm, проекционные связи).
  * `text_encoder.py` — Мультиязычный текстовый энкодер.
* `data/`
  * `dataset.py` — Загрузка данных, обработка формата 64x32/64x64, автоматический парсинг промптов.
* `utils/
  * `data_prep.py` — Уникальный процедурный генератор текстур для создания демо-данных.
  * `visualization.py` — Вспомогательные функции, включая генерацию интерактивного 3D skinviewer на трехмерной библиотеке Three.js.
* `dataset/` — Папка для ваших тренировочных скинов.
* `checkpoints/` — Веса обученной нейросети.
